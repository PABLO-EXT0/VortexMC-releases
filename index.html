Requirements

  • No Java needed. VortexMC downloads the right one for each Minecraft version.
  • Windows: Microsoft Edge WebView2 (already on current Windows 10 and 11).
  • Linux: GTK and WebKitGTK. On Debian and Ubuntu that is usually python3-gi and gir1.2-webkit2-4.1.

Getting started

  1. Open VortexMC and finish the first-run setup.
  2. Sign in with Microsoft, or use an offline profile.
  3. Create an instance: pick a version and a loader, or Horizon.
  4. Open Discover to add mods, shaders and packs, then press Launch.
About Horizon. Horizon support is an unofficial, experimental integration with the independent Horizon project. For now multiplayer is offline-only, Java mods do not run on Horizon, and native Horizon mods are compiled on your machine, so VortexMC asks you to confirm before it builds any. VortexMC is not affiliated with the Horizon project.
